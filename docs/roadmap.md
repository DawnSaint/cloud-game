# Cloud Game 项目路线图

> 云游戏平台开发规划，前期聚焦 Avalon Online。项目从纯前端起步，逐步引入后端服务。


---

## v0.1.0 — 后端基础设施

搭建服务端骨架，打通前后端实时通信链路。

- [ ] 安装 MongoDB，配置本地开发环境连接
- [ ] 服务端数据库层（`server/db/`）：连接管理、基础 Model 定义（参考上游 `_reference/packages/backend/src/db/models/`）
- [ ] 迁移实时通信至 Socket.IO — 替换 `useSocket.ts` 原生 WebSocket 封装，引入 `socket.io-client`（前端）+ Socket.IO（Nitro 服务端）
- [ ] 基础房间 REST API（`server/api/rooms/`）：创建、列表、详情
- [ ] 房间 Socket 事件协议：创建/加入/离开房间，房间状态广播（参考 `_reference/packages/types/api/sockets.ts`）
- [ ] 前端房间大厅 UI：房间列表、创建房间表单、加入/离开房间

---

## v0.2.0 — 游戏引擎与房间管理

实现服务端游戏引擎核心，支持完整的房间生命周期。

- [ ] 游戏状态类型定义（参考 `_reference/packages/types/game/`）
- [ ] 服务端游戏引擎（`server/game/`）：游戏初始化、角色分配、回合管理
- [ ] 基础角色类型与逻辑（参考 `_reference/packages/types/game/roles.ts`）
- [ ] 房间状态同步：玩家列表、准备状态、房主权限
- [ ] 游戏启动流程：房主开始游戏 → 角色分配 → 首夜信息展示
- [ ] 前端房间页面重构：玩家列表、准备/开始、角色揭示

---

## v0.3.0 — 核心玩法循环

实现 Avalon 完整回合制玩法。

- [ ] 组队选择：队长轮流提名队伍成员
- [ ] 队伍投票：赞成/反对，连续拒绝判定
- [ ] 任务执行：成功/失败（邪恶方可选失败）
- [ ] 刺杀阶段：刺客选择刺杀目标
- [ ] 胜负判定：任务失败数 / 刺杀梅林 / 连续投票拒绝
- [ ] 游戏结束：身份揭示、结果展示
- [ ] 基础角色完整支持：梅林、忠臣、爪牙、莫甘娜、派西维尔

---

## v0.4.0 — 游戏体验完善

补齐游戏体验，提升可玩性。

- [ ] 更多角色支持（奥伯伦、莫德雷德、布里安娜等，参考 `_reference/packages/backend/src/core/game/addons/`）
- [ ] 游戏设置面板：角色配置、人数限制
- [ ] 房主控制面板：踢人、设置调整、游戏管理
- [ ] 断线重连：Socket.IO 内置重连 + 服务端状态恢复
- [ ] 游戏历史记录：持久化到 MongoDB，前端展示
- [ ] 基础 UI/UX 打磨：动画过渡、响应式布局、错误提示

---

## v0.5.0 — 测试与质量保证

全面测试覆盖，修复已知问题，发布前的质量关卡。

- [ ] 游戏引擎单元测试：角色分配、回合流转、胜负判定全覆盖
- [ ] Socket 事件集成测试：房间生命周期、游戏流程端到端
- [ ] 前端组件测试：关键交互路径
- [ ] 类型检查：`vue-tsc --noEmit` 零错误
- [ ] 已知 Bug 修复与边界情况处理
- [ ] 性能优化：首屏加载、Socket 消息频率

---

## v1.0.0 — 平台化

从单游戏项目升级为云游戏平台，引入用户体系。

- [ ] 用户认证系统：注册、登录、会话管理
- [ ] 用户资料：昵称、头像、个人设置
- [ ] 数据统计：胜率、角色使用统计、游戏时长
- [ ] 排行榜：按游戏、按角色、按时间维度
- [ ] 大厅 UI 重构：集成用户信息、推荐房间、快速匹配
- [ ] 多游戏平台架构：游戏注册机制、通用房间系统
